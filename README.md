# Impettus IA Hub — downloads

Canal oficial de instaladores Windows x64 e atualizações do Impettus IA Hub, do Grupo Impettus.

Acesse **Releases** para baixar o instalador (Setup). A versão instalada verifica e baixa atualizações automaticamente. A versão portátil é atualizada por novo download.

O código de desenvolvimento é mantido em repositório privado. Este repositório contém apenas informações de distribuição, binários, manifestos e hashes. Os downloads não incluem credenciais nem dados da empresa.

## Estado do produto

Interface demonstrativa, sem APIs de IA, autenticação ou backend. O histórico é local ao computador. Não utilizar dados sensíveis.

## Verificação dos downloads

Compare o SHA-256 do arquivo com SHA256SUMS.txt na mesma Release. O aplicativo ainda não possui certificado comercial de assinatura de código; políticas do Windows ou da organização podem exigir validação da TI.
